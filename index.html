03开源

APUS AI 开源 Personal Agent 产品 Reflex Agent

时间 2026-10-13 发布 · 10-14 报道 来源渠道 量子位（媒体）
背景

Agent 的「外壳」（Harness）过去主要靠代码和提示词来组织，由模型自己承担核心决策是另一种思路。

内容

据文中所述，APUS AI 于 10 月 13 日宣布开源 Personal Agent 产品 Reflex Agent：它基于自研的开源决策模型 Reflex 构建 Harness，并配合 Continuum 记忆引擎，由决策模型承担模型路由、技能选择、结果审查与执行监督，形成「决策—执行—反馈—再决策」的循环（原文称 Loop Working）。文中提到，据 APUS AI 实验室实测，其在相关测试场景中的响应速度最快可达 Claude Code、Codex 等主流 Agent 的 3 倍；并特别说明所谓「无限上下文」并非突破单次调用的输入长度限制，而是让记忆与任务周期不再完全受限于单次窗口。

原文：qbitai.com/2026/10/503165.html
04具身智能

破晓智能联合天珑移动发布全身全模态数据采集系统 SeePhys Hub

时间 2026-10-14 12:51 来源渠道 量子位（媒体）
背景

机器人训练卡在数据上：动捕与真机数据精度高但采集成本高，第一视角（Ego）数据轻量，但缺少身体姿态和接触力度这类信息。

内容

围绕「人类操作数据能否突破机器人本体采集的规模限制」，破晓智能联合天珑移动发布全身全模态数据采集系统 SeePhys Hub。按文中描述，整套设备由一个四目头环、两个腕部手环、三个腰腿部动作追踪器和一副触觉手套组成，通过视觉与运动信号融合恢复全身姿态，并按任务需求采集手部接触压力。

06行业观察

雷锋网分析：Codex Harness 开源之后，AI 公司的护城河变了

时间 2026-09-30 16:24 来源渠道 雷锋网（分析文章）
背景

文章把模型比作输出推力的发动机，把 Harness 比作传动系统：它负责管理上下文、调用工具、保存状态、控制权限，并在任务失败后继续推进，把不确定的智能转成稳定的交付。

内容

文章回顾了 OpenAI 于 8 月 19 日开源 Codex Harness 后开发者的反应——不少长期做 Agent Harness 的开发者表示振奋，因为过去只有少数顶尖产品掌握的能力开始向更多开发者和企业开放。作者的核心判断是：随着这类最佳实践开源，Harness 正从「私产」变成「公器」，其本身的稀缺性在快速下降，过去靠 Harness Engineering 建立的技术领先也更容易被学习和复制。
